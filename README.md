# Snehith Infra — personal design templates

Static HTML/CSS/JS landing-page samples for **Snehith Infra** (Hyderabad software company: products, services, maintenance).

## Browse

- Open [`versions.html`](./versions.html) for the full gallery (v1–v135).
- Open [`index.html`](./index.html) for v1.
- On any version page, use **← / →** arrow keys to jump between versions (`version-nav.js`).

## Structure

| Path | Description |
|------|-------------|
| `index.html` | Version 1 (root) |
| `v2/` … `v135/` | Individual design systems |
| `versions.html` | Gallery index |
| `version-nav.js` | Shared arrow-key navigator |

Each version is self-contained (`index.html` + `css/tokens.css` + `css/styles.css`), with optional inline motion scripts on later samples.
